ℹ️ Instructions & Requirements

Required Columns:

  • SM IP - Required, must be unique, must be valid IP address
  • Location - Required, will be created if doesn't exist

Optional Columns:

  • AP Name - Access Point name
  • AP IP - Access Point IP address
  • CID - Customer/Circuit ID
  • Device Name - Name of the device/organization

Import Process:

  1. Download the template Excel file
  2. Fill in your device data (one device per row)
  3. Ensure SM IP and Location are filled for each row
  4. Upload the completed file
  5. System will:
    • Check for duplicate SM IPs (skip duplicates)
    • Validate IP addresses
    • Create new locations automatically if they don't exist
    • Import all valid entries
    • Show detailed results

Tips:

  • Keep the column headers exactly as in the template
  • Don't leave SM IP or Location empty
  • New locations will be created without a region (assign region later)
  • Duplicate SM IPs will be skipped automatically
  • Invalid IP addresses will be rejected
